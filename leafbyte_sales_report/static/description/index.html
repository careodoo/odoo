Overview

Sales Report

This module will show all sales records made from the system.


- This is the sales report with all the necessary fields.




- You can check POS orders only by applying 'POS Orders' filter.




- You can check Sale orders only by applying 'Sale Orders' filter.




- Filter / groupby the records however you like and then simply Export Filtered data by clicking on Export button.
